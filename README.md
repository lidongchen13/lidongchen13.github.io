# Personal homepage of Lidong Chen

Static site (plain HTML/CSS/JS, no build step), hosted on GitHub Pages at
https://lidongchen13.github.io.

## Edit

- `index.html` — all page content (hero, bio, publications, contact)
- `styles.css` — colors, fonts, layout (design tokens live in `:root`)
- `script.js` — dark-mode toggle and mobile menu

Commit and push to `master`; GitHub Pages redeploys automatically.

## Style

Design language inspired by a minimal academic site: cream paper background,
plum accent, teal signal color, Newsreader / Manrope / JetBrains Mono fonts,
with a light/dark theme toggle.
